[English profile](README.md)

로컬 우선 AI 도구, 자동화 유틸리티, 작업자 중심 워크스페이스를 만듭니다. 기본 원칙은 간단합니다. 먼저 점검하고, 필요한 만큼만 수정하고, 실제로 검증한 뒤, 다음 사람이 덜 막히게 남깁니다.

## 집중 분야

- 로컬 AI 워크스페이스와 오케스트레이션 인터페이스
- Windows 생산성 자동화와 Click to Do 스타일 도구
- TypeScript, Python, AutoHotkey 기반 실전 개발
- GitHub 문서화, CI 점검, 코드 리뷰

## 대표 작업

- [Artemis Orchestration App](https://github.com/Artemis-ignis/artemis-orchestration-app): 채팅, 파일, 오케스트레이션, 로그, 런타임 상태를 묶는 로컬 작업공간
- [Open Click to Do](https://github.com/Artemis-ignis/open-click-to-do): Windows용 OCR, 복사, 번역 오버레이
- [Copilot AI Memory Saver](https://github.com/Artemis-ignis/copilot-ai-memory-saver): 유휴 AI 워크로드 메모리 점유를 줄이는 도구
- [AgentDeck RPG](https://github.com/Artemis-ignis/agentdeck-rpg): 유지보수자를 위한 로컬 우선 AI 에이전트 콕핏
