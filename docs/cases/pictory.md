# 픽토리 · 사진 정리의 신뢰와 사용 권한

[프로필로 돌아가기](../../README.md)

## 문제와 제품 흐름

사진 정리의 번거로움을 줄이면서도 사용자가 분류 결과를 이해하고 사진 노출과 저장 범위를 알 수 있어야 했습니다. 홈에서 정리 목적을 선택하고, 분류별·날짜별 묶음을 검토한 뒤 보관하는 흐름을 구성했습니다.

프로젝트의 앱인토스 제출용 이미지로, 샘플 사진을 사용한 구현 화면입니다.

## 세 가지 제품 결정

1. **결과 저장 범위:** 원본 사진을 영구 저장하는 대신 최근 결과의 작은 썸네일·분류 메타데이터를 관리합니다. 민감·확인 필요·문서류 후보는 실제 썸네일 대신 대체 이미지를 저장하도록 했습니다.
2. **보상 지급 기준:** 광고 화면 종료와 보상 획득을 구분했습니다. 네이티브 보상 이벤트를 확인한 뒤에만 크레딧을 반영하는 기준을 두었습니다.
3. **유료 권한 기준:** 클라이언트 플랜 표시와 실제 결제 권한을 구분하고, 서버 원장과 결제 상태 확인을 기준으로 삼았습니다.

## 나의 기여와 현재 상태

사용자 흐름과 정보 구조, 민감 이미지 처리, 무료·보상·구독의 적용 기준을 정하고 AI 도구를 활용해 구현·검수했습니다. 홈·정리·보관 화면과 서버 처리 연결부가 있습니다. 실제 토스 앱에서 권한·분류·광고·결제·삭제를 확인하는 것이 출시 전 과제입니다.

## 다음 검증

선택한 사진에서 보관 후보를 찾는 데 걸리는 과정, 잘못 묶인 결과를 알아차리고 수정할 수 있는지, 데이터 삭제 설명을 이해하는지를 과업 테스트로 확인하려 합니다. 정리 완료율과 민감 이미지 노출 오류를 함께 관찰할 계획입니다. 아직 사용자 성과 수치는 없습니다.
