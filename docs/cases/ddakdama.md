# 딱담아 · 선택 오류를 줄이는 AI 쇼핑 흐름

[프로필로 돌아가기](../../README.md)

## 문제와 판단

AI가 장보기 목록을 추천해도 상품 검색·용량 확인·수량 비교는 사용자에게 남았습니다. 특히 100mg은 성분 함량이고 240정은 한 병의 내용물입니다. 이를 구매 수량과 혼동하면 잘못 담을 수 있어, 상품 정체성·포장 단위·요청 수량을 독립적으로 표현했습니다.

## 사용자가 확인할 수 있는 단계

목록 입력 → 상품 후보 비교 → 담기 전 가격·규격 확인 → 장바구니 변화 확인 → 실패 항목 복구.

![후보 비교](https://raw.githubusercontent.com/Artemis-ignis/Artemis-ignis/main/docs/assets/pm-portfolio/ddakdama-compare.jpg)

## 포기한 자동화와 남긴 통제

정확한 후보만 자동 선택 대상으로 두고 유사 후보는 검토 대상으로 남겼습니다. 상품 일부를 확인할 수 없으면 전체를 성공 처리하지 않고 문제 항목을 화면에 남깁니다. 자동 결제는 제품 범위에 포함하지 않았습니다.

![부분 실패와 다음 행동](https://raw.githubusercontent.com/Artemis-ignis/Artemis-ignis/main/docs/assets/pm-portfolio/ddakdama-recovery.jpg)

두 이미지는 실제 구현 UI를 담은 제출용 데모 자료입니다. 상품·가격 데이터는 재현 가능한 샘플이므로 실거래 검증이나 구매 성과로 읽지 않습니다.

## 나의 기여와 결과

문제 정의, 사용자 흐름, 수량 판단과 완료 기준을 정하고 AI 도구를 활용해 구현·회귀 검증을 진행했습니다. 파서·수량 계획·후보 비교·결과 화면과 실행 검증 로직이 저장소에 있습니다.

## 다음 검증

사용자가 직접 입력한 장보기 목록으로 과업 테스트를 진행하고, 후보 재선택 사유·중도 이탈 단계·오류 복구 여부를 기록하려 합니다. 완료율은 과업 시작 대비 사용자 검토 후 전달 완료로 정의하고, 잘못된 상품·수량 전달을 함께 측정해야 합니다. 이 항목들은 측정 계획입니다.
