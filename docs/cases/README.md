## 딱담아 · 장보기 추천을 실제 구매 준비로 연결하기

장볼 품목을 정한 뒤에도 상품을 다시 검색·비교하고 장바구니를 채워야 하는 반복 작업을 줄이려는 제품입니다. GPTs에서 시작한 목록을 Chrome 확장 프로그램으로 이어 쿠팡 장바구니 준비를 돕습니다.

[만든 이유 → 제품 흐름 → 나의 판단과 역할 → 현재 결과](ddakdama.md)

## 여사친 (구 픽토리) · 여행 사진을 골라주는 친구

여행 후 비슷한 사진 중 무엇을 남길지 고르는 부담을 줄이려는 앱인토스 서비스입니다. 범용 사진 정리에서 여행 사진 선택·비교·앨범으로 개편 중이며, 실제 개편 화면을 소개합니다.

[만든 이유 → 제품 흐름 → 나의 판단과 역할 → 현재 결과](pictory.md)

## Clunk · 게임 제작자가 에셋 준비를 쉽게 시작하기

게임에 필요한 에셋을 확보·제작·검사하고 프로젝트에 적용할 준비를 한곳에서 이어가려는 무료 베타입니다. 현재 수요와 상업적 품질은 검증 중입니다.

[만든 이유 → 제품 흐름 → 나의 판단과 역할 → 현재 결과](clunk.md)

각 사례의 사용자 문제는 제품 기획에서 설정한 문제입니다. 실제 인터뷰 결과나 정량 성과가 없는 항목은 검증 계획으로 표시합니다.
