[프로필로 돌아가기](../../README.md)

## 문제 재정의

게임 제작자는 에셋의 외형을 고른 뒤에도 파일 규격·실제 내용·사용 조건을 확인해야 합니다. 생성 기능에 더해 선택한 결과를 믿고 사용할 근거가 필요하다고 보고, 마켓과 파일 검사·최적화·검사 기록을 연결했습니다.

![Clunk 운영 홈](https://raw.githubusercontent.com/Artemis-ignis/Artemis-ignis/main/docs/assets/pm-portfolio/clunk-home.png)

2026.09.08 운영 홈 캡처입니다. 홈의 홍보 문구는 모든 기능의 완성이나 전 엔진 검증의 증거가 아닙니다.

## 제품 결정

- **파일 사실을 확인:** 설명과 미리보기 외에 실제 파일을 읽고 구조·용량·메타데이터를 확인하는 검사 흐름을 뒀습니다.
- **원본과 결과를 구분:** 변환 후 별도 출력과 재검사를 연결하고, 해시를 통해 입력·출력·검사 기록을 추적하는 기준을 세웠습니다.
- **품질 판정을 구분:** 자동 검사 통과, 실제 렌더 확인, 사람이 승인한 품질을 별도 상태로 관리했습니다.

## 검증이 바꾼 화면

시작 버튼에서 마켓으로 이어지는 동선을 확인하고, 에이전트 미리보기 안내를 구분했습니다. 이후 데스크톱·모바일 화면 맞춤과 3D 미리보기 위 스크롤 동작, 파일 검사 점수 카드의 접근성을 실제 브라우저에서 확인하며 개선했습니다.

## 나의 역할과 확인 범위

제품 방향·요구사항·우선순위·품질 기준과 화면 검수를 맡았습니다. 코드·에셋 후보 생성에는 AI 도구를 활용했습니다. 2026.09.08 작업 기록에는 운영 홈·마켓 이동과 파일 생성·저장·검사·최적화·GLB/Passport 다운로드 검증 기록이 있습니다. 이는 모든 파일의 게임 사용 적합성이나 고객 성과를 뜻하지 않습니다.

## 다음 결정에 필요한 근거

게임 제작자가 어떤 파일을 선택하고 어떤 이유로 포기하는지, 다운로드 후 목표 엔진에서 열 수 있는지, 같은 과업에 다시 사용하는지를 인터뷰·과업 관찰로 확인하려 합니다. 현재 외부 활성 사용자·유료 매출·전환율은 확인되지 않았습니다.
