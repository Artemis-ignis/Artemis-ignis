# 여사친 · 여행 사진 선택에 집중하는 개편 브리프

## 1. 문제와 사용자 과업

**대상:** 여행 후 비슷한 사진이 많이 남아 무엇을 보관할지 고르기 어려운 사람.

**과업:** “여행 사진을 정리할 때, 비슷한 컷을 쉽게 비교하고 내가 좋아하는 순간을 골라 하나의 앨범으로 남기고 싶다.”

**가설:** 범용 분류 메뉴보다 여행 사진 선택에 맞춘 추천·비교·앨범 흐름이 선택 부담을 줄일 것이다. 아직 인터뷰·실험으로 검증된 결론은 아닙니다.

## 2. 무엇을 바꾸고 무엇을 빼는가

| 영역 | 기존 픽토리 설명 | 여사친 개편 방향 |
| --- | --- | --- |
| 해결할 일 | 쌓인 사진의 범용 분류·정리 | 여행 후 남길 사진 고르기 |
| 핵심 흐름 | 정리 목적·분류 결과·보관 | 여행 사진·같이 고르기·여행 앨범 |
| 추천 역할 | 분류 결과 제공 | 밝기·선명도 참고 후보와 유사 컷 비교; 최종 선택은 사용자 |
| 기본 이용 | 사용량·광고 보상·AI 크레딧 중심 설명 | 기본 무료 정리, 크레딧·광고로 흐름을 막지 않음 |
| 브랜드 | 기존 파란색 사진 정리 앱 | 코랄·크림색의 가상 여행 친구 |

## 3. 요구사항과 수용 기준

| 사용자 단계 | 요구사항 | 확인할 기준 |
| --- | --- | --- |
| 사진 가져오기 | 한 번에 최대 100장, 기기 안에서 작업본 처리 | 권한 거절·취소·손상 이미지 안내; 가져오지 못한 상태를 성공으로 표시하지 않음 |
| 같이 고르기 | 추천·유사 컷·장면/날짜 묶음, 수동 수정 | 사용자가 추천을 바꾸고 원하는 컷을 선택할 수 있음 |
| 여행 앨범 | 선택한 사진으로 이름 있는 앨범 생성 | 새 여행 시작·재접속 후 기존 앨범 유지; 선택하지 않은 사진은 새 앨범에 넣지 않음 |
| 내보내기 | 작업본 ZIP 제공 | 저장 요청과 완료 구분; 실제 저장 파일을 열어 내용 확인 |
| 보관 해제 | 앱 내부 상태 변경 | 실제 갤러리 원본 삭제로 오인하지 않도록 안내 |

## 4. 먼저 검증할 범위

무료 정리와 100장 보관, 앨범 완성과 ZIP 내보내기를 기본안으로 둡니다. 유료 보관 확장은 후보이며 기본 비활성입니다. 구독 가치·가격·전환율은 검증되지 않았고, 실제 상품과 주문·복원·환불 검증 전 활성화하지 않습니다.

사진은 기기 안에서 처리하며 작업본은 최대 너비 1280px입니다. ZIP은 원본 백업이 아닙니다. 기기 변경·앱 데이터 삭제에도 유지되는 클라우드 보관을 제공한다고 설명하지 않습니다.

## 5. 검증 계획 — 성과가 아니라 다음 질문

- **선택 부담:** 같은 여행 사진 묶음에서 갤러리와 여사친의 선택 완료 시간·앨범 완성 여부 비교. 순서 효과를 줄이도록 과업 순서를 교차합니다.
- **추천의 유용성:** 추천을 바꾼 이유와 남긴 컷의 만족도를 관찰합니다. 선명도가 낮아도 의미 있는 추억일 수 있습니다.
- **퍼널:** 사진 선택 시작 → 결과 도달 → 1장 이상 보관 → 여행 앨범 생성의 단계별 완료를 확인합니다.
- **반복 가치:** 7일 내 재방문을 후보 지표로 보되, 여행 빈도의 영향을 함께 해석합니다.
- **신뢰:** 원본 삭제 여부·작업본 내보내기·기기 내 보관의 차이를 사용자가 이해하는지 확인합니다.

현재 별도 외부 분석 전송은 구현하지 않았습니다. 향후 지표에 사진·파일명·얼굴 정보를 넣지 않으며, 목표 전환율이나 시간 절감 수치를 실측 성과로 쓰지 않습니다.

## 6. 현재 상태

개편 UI와 핵심 흐름은 구현되어 있습니다. 실제 토스 단말의 사진 권한·파일 저장, 정식 개인정보처리방침 확정, 배포 검수와 사용자 과업 검증은 남아 있어 **출시 준비 중**으로 표시합니다.
