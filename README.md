## 01 · Clunk Games · 웹 게임 3개와 모바일 게임 3개 출시·운영

개인사업자(아르테미스, 2026.08~)로 운영하는 캐주얼·퍼즐 게임 브랜드입니다. 웹 게임은 가입·설치 없이 링크로 시작해 모든 플레이어가 같은 블록 순서로 주간 순위를 겨룹니다. 모바일 게임 3개는 Google Play, 토스 앱인토스, 원스토어에 냈습니다.

<img src="assets/games.jpg" width="100%" alt="모바일 게임 Clunk Tower, Hexa Garden, Glass Harbor 대표 그림" />

- **지표 설계** 게임 이벤트(방문·시작·완료·공유)와 일별 이탈을 보는 운영자 화면(09.24), 유입 경로 저장(10.29), 토스용 첫 10초 이벤트(11.03)
- **이탈 분석** 홈 방문자 125명 중 52%가 게임 페이지로 넘어가지 않음 → 첫 화면 버튼 3개 중 2개가 스크롤만 하던 구조를 원인 후보로 보고 게임으로 바로 가게 수정(10.21)
- **랭킹 공정성** 퍼즐은 서버가 입력 기록을 재생해 점수 재계산, 탑은 높이 상한과 지난 4주 기록 기준선으로 위조 기록 보류(10.29 위조 29.9m 재현 확인)
- **장애 대응** DB 무료 한도 초과로 약 6시간 중단(09.25) → 최고 기록·일일 순위표만 읽게 바꾸고 기존 순위 110건 대조 후 재개. 결제·로그인 장애 원인 2개 수정(10.26)
- **유입 실험** 토스 프로모션 7,900원·1,580명 유입, 첫판 완료 13~15%, 다음 날 재방문 0.8% → 중단. 대상을 20대로 좁힌 재실험에서 첫판 완료 45%
- **출시 전 검수** AI 점검에서 버그 후보 58건, 3회 검증 중 2회 이상 확인된 52건만 수정

## 02 · DANGJANG · 패스트캠퍼스 AI 심화캠프 10기 5인 팀 프로젝트

키·몸무게가 같아도 체형 비율이 달라 온라인에서 산 옷이 맞지 않는 문제를 다룬 앱입니다. 이미 잘 맞는 내 옷 한 벌과 새 옷의 치수를 비교합니다. 팀장·디자이너 출신 팀원 등 5명이 함께 만들었고, 아래는 제가 맡은 부분입니다.

<img src="assets/app-logic-flow.jpg" width="100%" alt="앱 로직 흐름도. 앱 실행에서 홈, 상품 상세, 구매, 옷 등록, 내 옷장, 마이, 로그인 7개 흐름으로 갈라지는 판단 순서도" />

- **앱 로직 흐름도** 팀 화면 흐름을 판단 지점 단위로 점검해 8구역·판단 지점 62개(53개 새로 정의)로 정리, 앱 실행에서 7개 흐름으로 갈라지는 한 장으로 팀 피그마에 공유
- **조사** 인터뷰 질문지 24문항 작성, 팀 인터뷰 5건 분석(반복 패턴 6개), 설문 원자료(유효 23명) 재분석, 배포 전 가상 응답 60명으로 문항 점검
- **옷 등록 기능** 상품 링크·구매 내역 캡처·A4와 함께 찍은 사진·직접 입력 4가지를 치수 확인 화면 하나로 모음. 측정이 불확실하면 숫자 대신 다시 찍기 안내. 합성 사진 48장 기준 평균 오차 0.35cm(실제 옷 시험 전)
- **정책 맞추기와 인계** 팀 정책 문서와 데모를 43개 항목으로 대조해 다른 27개 수정 시작, 팀장 요청으로 데모 서버 기능을 팀 프로토타입에 붙이도록 인계
- **신기능 제안** 팀 첫 제안서 PR(#5)을 올렸고 팀원 3명이 같은 형식으로 뒤따름

<img src="assets/wireframes.jpg" width="72%" alt="팀 피그잼에 올린 와이어프레임 일부" />

## 03 · 딱담아 · ChatGPT 장보기 목록을 쿠팡 장바구니로

화장품·생활용품 5종을 쿠팡에서 직접 사며 단계마다 적어 보니, 살 물건을 정한 뒤에도 재검색·규격 대조·개수 계산에 40분 넘게 걸렸습니다. 이 구간을 줄이려고 만든 ChatGPT 앱과 Chrome 확장 프로그램입니다. 사용자가 승인한 상품만 담고 결제와 비밀번호는 다루지 않습니다.

<img src="assets/ddakdama-try.jpg" width="100%" alt="딱담아 체험 페이지에서 장보기 목록을 상품 후보로 바꾼 결과 화면" />

- '100mg 240정' 1통을 240개로 읽는 오류를 테스트에서 찾아 개수 계산을 AI 답 대신 규칙으로 처리 → 합성 장보기 목록 50줄 기준 해석 정확도 64% → 98%
- 첫 인터뷰에서 가설과 다른 구매 행동을 보고 사용자를 목록 우선형과 검색 우선형으로 나눠 첫 대상을 정함
- 5명·2주 사용 테스트는 아직 하지 않았고, 시작 전에 판단 기준(추천 후보 채택 70% 이상 등)을 적어 둠
