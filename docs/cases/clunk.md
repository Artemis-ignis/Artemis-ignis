# Clunk · 게임 제작자가 에셋 준비를 쉽게 시작하기

[포트폴리오 홈](../../README.md) · [이력서](../resume.ko.md)

## 누구의 어떤 문제에서 시작했나

게임 아이디어가 있어도 필요한 에셋을 찾거나 제작하고, 파일 규격과 내용을 확인하고, 제작 환경에서 쓸 수 있게 준비해야 하는 사람을 위한 제품입니다. 흩어진 도구와 준비 작업 때문에 게임 제작에 도달하기까지 생기는 부담을 줄이고 싶었습니다.

## 어떤 변화를 만들고 싶었나

에셋 탐색·제작·확인·사용 준비를 한곳에서 이어가며, 제작자가 결과물을 가지고 다음 작업으로 넘어갈 수 있게 하려 했습니다.

이는 제품 기획에서 설정한 문제와 해결 가설입니다. 사용자 인터뷰나 측정된 개선 효과로 제시하는 내용은 아닙니다.

## 제품 경험을 어떻게 구성했나

**에셋 탐색·제작 → 미리보기 → 파일 검사·최적화 → 다운로드·사용 준비**

마켓·상품 상세·미리보기와 실제 파일 검사 흐름을 연결했습니다. 에셋을 보여주는 것과 제작자가 사용할 수 있는 결과물을 제공하는 것 사이에 추가 작업이 있었기 때문입니다.

## 구현 과정에서 무엇을 판단했나

자동 파일 검사, 실제 렌더 확인, 사람의 품질 승인을 구분했습니다. 시작 버튼의 마켓 이동, 모바일 화면 맞춤과 3D 미리보기 위 스크롤도 검수하며 개선했습니다.

## 내가 맡은 일

제품 방향·요구사항·우선순위·완료 기준과 화면 검수를 맡았습니다. 코드와 에셋 후보 생성에는 AI 도구를 활용했습니다.

## 현재 보여줄 수 있는 결과

운영 베타와 파일 생성·저장·검사·최적화·다운로드 검증 기록이 있습니다. 이는 모든 에셋의 엔진 적용이나 전체 게임 제작 기능의 완성을 뜻하지 않습니다.

[라이브 제품](https://clunk.games) · [공개 파일 검사 도구](https://github.com/Artemis-ignis/clunk-mcp)

Clunk 소스 저장소와 내부 문서는 비공개입니다.

## 다음에 무엇을 검증할 것인가

제작자가 목표에 맞는 에셋을 찾고 다운로드한 뒤 자신의 환경에서 사용하는 과업을 관찰하려 합니다. 사용 준비 완료 여부·포기한 단계·다시 사용하려는 이유를 확인할 계획입니다. 아직 측정된 고객 수·매출·전환 개선 수치는 없습니다.

## 이 경험에서 배운 것

기능을 연결했어도 실제 파일과 화면에서 확인해야 할 일이 남았습니다. 요구사항과 완료 기준을 세우고 직접 검수하는 과정이 제품 약속을 현실적인 범위로 구체화하는 데 도움이 됐습니다.
