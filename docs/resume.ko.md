# 박준성

## 신입 PM / PO · 서비스 기획

시장 조사·콘텐츠 기획 경험을 바탕으로 사용자의 반복 작업을 제품으로 풀어내는 신입 PM 지원자입니다. 딱담아·여사친(구 픽토리)·Clunk를 만들며 제품 방향과 사용자 흐름을 정하고, AI 도구를 활용해 구현·검수했습니다.

[GitHub 프로필](https://github.com/Artemis-ignis) · [English resume](resume.en.md)

## 지원 방향

- 서비스 기획 / Product Manager / Product Owner
- AI-native 제품, SaaS, 커머스·콘텐츠·게임 도메인
- 문제 정의, 요구사항 구조화, 사용자 흐름, 우선순위, 제품 QA가 필요한 초기 제품팀

## 핵심 요약

- 메타체인에서 블록체인 게임 콘텐츠 기획·시장 조사·제안서·마케팅을 경험했습니다.
- 현재 Clunk 개인 제품 프로젝트에서 제품 방향, 요구사항, 품질 기준, 브라우저 흐름과 실제 파일 검증을 직접 설계·검수하고 있습니다.
- AI 도구가 만든 결과를 그대로 성과로 포장하지 않고, 자동 검사·실제 렌더·사람의 품질 판단을 구분해 기록합니다.
- 확인된 사실, 제품 가설, 입사 후 계획을 분리해 팀의 다음 의사결정을 돕는 방식을 지향합니다.

## 대표 제품 사례

### 딱담아 · 장보기 추천을 실제 구매 준비로 연결하기

- **문제:** 장볼 목록을 정한 뒤에도 상품을 하나씩 검색·비교하고 장바구니를 채워야 하는 반복 작업.
- **역할·판단:** 목록 → 후보 비교 → 담기 전 확인 → 결과 흐름을 정의했습니다. 상품과 포장·구매 수량을 구분하고, 불확실한 항목은 사용자가 검토하는 동선을 설계했습니다.
- **현재 결과:** 웹·확장 프로그램·ChatGPT 앱 연결 흐름과 데모를 만들었습니다. AI 도구를 활용해 구현·검수했으며, 사용자 구매 준비 시간과 완료율은 향후 측정 과제입니다.
- [화면과 제품 사례](cases/ddakdama.md) · [저장소](https://github.com/Artemis-ignis/ddakdama)

### 여사친 (구 픽토리) · 여행 사진을 골라주는 친구

- **문제:** 여행 후 비슷한 사진을 하나씩 비교하며 남길 컷을 결정해야 하는 부담.
- **역할·판단:** 범용 사진 정리에서 여행 사진 선택으로 제품 방향을 구체화했습니다. 사진 선택 → 추천·유사 컷 비교 → 여행 앨범 흐름을 구성하고, 최종 선택은 사용자에게 맡기며 기본 정리는 무료로 제공하도록 범위를 정했습니다.
- **현재 결과:** 개편 화면과 사진 선택·추천·비교·앨범 흐름 구현, 출시 준비 중입니다. 실제 토스 단말의 사진 권한·파일 저장 및 선택 부담 감소는 검증 과제입니다.
- [실제 화면과 개편 사례](cases/pictory.md) · [저장소](https://github.com/Artemis-ignis/pictory-apps-in-toss)

### Clunk · 게임 제작자가 에셋 준비를 쉽게 시작하기

- **문제:** 게임에 필요한 에셋을 구하고 제작 환경에서 사용할 수 있게 준비하는 작업이 여러 도구에 흩어져 있는 상황.
- **역할·판단:** 제품 방향·요구사항·우선순위·품질 기준을 정했습니다. 탐색·미리보기와 파일 검사 흐름을 연결하고 AI 도구가 만든 결과를 실제 화면과 파일에서 검수했습니다.
- **현재 결과:** 운영 베타와 파일 생성·검사·다운로드 검증 기록이 있습니다. 제작자 인터뷰와 실제 사용 과업 검증을 통해 가치를 확인하려 합니다.
- [화면과 제품 사례](cases/clunk.md) · [라이브 제품](https://clunk.games) · 소스 저장소 비공개

## PM 작업 방식

문제 관찰 → 문제 정의 → 가설 수립 → MVP 범위 설정 → 구현·프로토타이핑 → 실제 근거로 검증 → 학습과 다음 우선순위 결정

문제 정의, JTBD, 사용자 여정, 요구사항, 수용 기준, 실패 경계, 출시 체크리스트를 제품 문서의 핵심으로 봅니다.
