## 대표 제품 사례

### 딱담아 · GPTs와 Chrome 확장 프로그램으로 쿠팡 장바구니 준비 연결하기

- **문제:** 장볼 목록을 정한 뒤에도 상품을 하나씩 검색·비교하고 장바구니를 채워야 하는 반복 작업.
- **역할·판단:** GPTs에서 시작한 목록을 Chrome 확장 프로그램으로 넘기는 흐름을 정했습니다. 목록 → 후보 비교 → 담기 전 확인 → 결과를 연결하고, 상품과 포장·구매 수량을 구분하며 불확실한 항목은 사용자가 검토하도록 했습니다.
- **현재 결과:** 웹·GPTs·Chrome 확장 프로그램 연결 흐름과 데모를 만들었습니다. 데모의 상품·가격은 샘플 데이터이며, 최신 빌드의 실제 구매 준비 시간·완료율·고객 성과는 측정하지 않았습니다.
- [화면과 제품 사례](cases/ddakdama.md) · [저장소](https://github.com/Artemis-ignis/ddakdama)

### 여사친 (구 픽토리) · 앱인토스에서 여행 사진을 골라주는 친구

- **문제:** 여행 후 비슷한 사진을 하나씩 비교하며 남길 컷을 결정해야 하는 부담.
- **역할·판단:** 범용 사진 정리에서 여행 사진 선택으로 제품 방향을 구체화했습니다. 사진 선택 → 추천·유사 컷 비교 → 여행 앨범 흐름을 구성하고, 최종 선택은 사용자에게 맡기며 기본 정리는 무료로 제공하도록 범위를 정했습니다.
- **현재 결과:** 앱인토스용 개편 화면과 사진 선택·추천·비교·앨범 흐름을 구현해 출시를 준비하고 있습니다. 실제 토스 단말의 사진 권한·파일 저장, 사용자 선택 부담 감소와 고객 성과는 검증 과제입니다.
- [실제 화면과 개편 사례](cases/pictory.md) · [저장소](https://github.com/Artemis-ignis/pictory-apps-in-toss)

### Clunk · 게임 에셋 확보·제작·검사·프로젝트 적용을 연결하는 무료 베타

- **문제:** 게임에 필요한 에셋을 구하고 제작 환경에서 사용할 수 있게 준비하는 작업이 여러 도구에 흩어져 있는 상황.
- **역할·판단:** 에셋 확보 → 제작·수정 → 파일 검사 → 프로젝트 적용이라는 목표 흐름의 제품 방향·요구사항·우선순위·품질 기준을 정했습니다. AI 도구가 만든 결과를 실제 화면과 파일에서 검수하고, 구조적 검사·시각적 품질·엔진 적용을 구분했습니다.
- **현재 결과:** 무료 공개 베타의 키트 카탈로그·검수 뷰어·게임 시제품과 파일 검사 도구를 공개하고 있습니다. 방문·사용이 아직 매우 적으며, 초기 제작자 인터뷰와 사용 로그로 수요를 확인한 뒤 실제 프로젝트 적용 과업을 검증할 예정입니다.

## AI 활용과 검증 경계

문제·사용자·우선순위·완료 기준과 품질 판단은 제가 맡고, AI 도구는 코드·문서·시각 자료 제작을 보조했습니다. 실행 결과는 브라우저·파일·테스트로 확인하며, 외부 고객 수·매출·전환율·PMF·시간 절감처럼 확인하지 못한 수치는 성과로 주장하지 않습니다. 실제 수행·제품 가설·입사 후 계획을 나누어 씁니다.
